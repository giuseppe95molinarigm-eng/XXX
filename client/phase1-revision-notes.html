This revision was built without InDesign, so we are not supplying .indd or .idml files: we could not open and check them, and a file nobody has checked is not a real source. Instead you have the parts InDesign uses directly: every map, flag and illustration as a true vector SVG, the fonts, and a grid specified in millimetres frame by frame, ready for the InDesign template in the layout phase.

QuestionOur recommendation
1Flag dots in a black-only interior. Your example in the Blueprint shows the dots in color, but the interior is specified in black only, and a black dot cannot show a color.Outline dots with the color name beneath (used on the samples). Printed color dots would mean four-color printing on every country page.
